# Locutor
Work-in-progress project for the development of a Latin-speaking LLM, both for conversation and translation.

# Current status

Note: the project is still in the very initial stage of corpus gathering and cleaning. Specifically, the uploaded scripts scrape about half a gigabyte of text from Latin Wikisource, perform deduplication and allow for orthography normalization and correction of typos - the latter two, although partly automatically implemented, do necessitate human feedback as well.
